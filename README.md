# Python в облаках

Учебная платформа Python: теория и задания, проектные курсы, мастерская, прогресс,
личные заметки и игровые награды. В исходниках сохранены Flask-сервер, основной
веб-интерфейс, React-клиент в процессе миграции и Android-клиент с локальным Pyodide.

Это исходный preview. Проверенные команды и ограничения конкретной публикации
указаны в `PUBLICATION.md`; наличие исходников не подтверждает готовность интернет-сервиса.
В репозитории нет рабочих баз учеников, ключей сессий или общедоступного аккаунта.

## Запуск

Нужны CPython 3.14 и Node.js для сборки учебного контента. Пример для PowerShell:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python -m pip install -r platform\requirements-dev.txt
.\.venv\Scripts\python build_tasks.py
$env:PYCLOUD_AI_ENABLED = '0'
$env:PYCLOUD_PORT = '18017'
Set-Location platform
..\.venv\Scripts\python server.py
```

После запуска откройте `http://127.0.0.1:18017` и создайте собственную учётную запись.
Сервер слушает HTTP на всех сетевых интерфейсах выбранного порта; TLS и внешний
доступ настраиваются отдельно. Занятый порт приводит к отказу запуска, существующий
процесс сохраняется.

Python-код веб-заданий выполняется серверным Docker-раннером. Его исходники лежат
в `platform/sandbox_web/`; нативного исполнения ученического кода вместо контейнера нет.
Нужен совместимый Docker runtime. На Windows текущий адаптер рассчитан на отдельно
настроенный WSL runtime; готовая установка такого окружения здесь не поставляется.
Без раннера интерфейс и теория доступны, а выполнение кода сообщает о недоступности среды.
Dockerfiles содержат версии зависимостей; локальные wheelhouse-кэши не включены.

## Контент и клиенты

`python_tasks_collection.md` и `platform_source_rules.py` — исходники заданий;
`build_tasks.py` проверяет исполняемые эталоны в CPython 3.14 и выпускает согласованный
набор веб- и Android-материалов. Сгенерированные задания вручную не правятся.

`platform/static/content-current.json` выбирает учебное поколение. Для него нужны
обе папки: `platform/static/course-content/<id>` и `platform/.course-content/<id>`.
Вторая содержит серверные учебные метаданные, а не данные учеников. Проверяемые
файлы должны сохранять точные байты и окончания строк.

React-клиент: `platform/frontend/`. Его сборка создаётся через `npm ci` и
`npm run build`; готовые зависимости и `dist/` в исходники не включены. Полное
равенство экранов с основным интерфейсом требует отдельной проверки.
Android-клиент: `android/`; для его сборки нужны JDK и Android SDK, собственные
локальные настройки и адрес вашего сервера. Ключи подписи и `local.properties`
в репозитории отсутствуют.

## Данные и ИИ

Учётные записи, прогресс, код, заметки, сессии и сведения наставника сохраняются
в локальной SQLite-базе внутри `platform/instance/`. Её расположение и ключ сессий
можно задать через `PYCLOUD_INSTANCE_DIR`, `PYCLOUD_DB_PATH`, `PYCLOUD_SECRET_FILE`.
Эти файлы и пользовательские экспорты не входят в исходную публикацию.

Удалённый наставник включается оператором через `PYCLOUD_AI_ENABLED=1` и использует
отдельно установленную, авторизованную Codex CLI. Модель выбирается через
`PYCLOUD_AI_MODEL`. Наставнику передаются выбранные вопрос/код и учебный контекст;
история и память зависят от настроек аккаунта. Расход запросов определяется вашим
аккаунтом провайдера. Готовые ключи и аккаунты здесь не поставляются.

В настройках можно отключить ИИ и контекст, настроить срок хранения и очистить
разделы истории. Очистка не удаляет ранее созданные резервные копии и уже
отправленные провайдеру сведения. Учебный архив и резервная копия всего экземпляра
имеют разные назначения и ограничения восстановления.

## Проверка

```powershell
$env:PYCLOUD_AI_ENABLED = '0'
Set-Location platform
..\.venv\Scripts\python -m pytest tests/ -q
```

Тестовый `conftest.py` использует временные базу и ключи, а внешние runtime-пути
подменяются синтетическими fixtures. Проверки Codex-транспорта используют mocks
и искусственные процессы, а не реальные обращения к модели. Дополнительный
защитный запуск, применённый при публикации, описывается в `PUBLICATION.md`.
Браузерные проверки и реальный Docker/Android runtime учитываются отдельно.

Лицензия Pyodide и manifest версии сохранены рядом с Android runtime.
Лицензия Symbols Nerd Font и данные о производном UI-шрифте находятся в
`platform/static/vendor/`. Сохраняйте эти уведомления при распространении.
