# Чистая публикационная копия — 29 октября 2026

Подготовлена из актуального combined working tree проекта, включая новые обязательные модули.
Исходный каталог и его незакоммиченные изменения сохранены. Старые Git-история и QA-пара,
реальные аккаунты/базы/секреты, экспорты учеников, графы, скриншоты, локальные окружения,
неактивные учебные поколения и браузерные live-login harnesses не входят в эту копию.
Тестовые логины согласованно заменены синтетическими; готового общего аккаунта нет.

## Исправлено в этой копии

- Платёж виртуальными каплями за Atlas использует собственную SQLite-транзакцию без
  постороннего неблокирующего AI-admission lock. Сохранены owner/balance/idempotence проверки.
- Проверка XLSX-задачи 56.8 моделирует конкурирующую запись на write boundary в CPython 3.14
  и проверяет Path/io/os/builtin сценарии; правильный ответ не заменялся.
- Возвращены необходимые runtime/Node QA исходники. Два смешанных harness разделены:
  сохранены офлайн-утверждения, браузерные ветки/Playwright/live server не подключены.
- ИИ — opt-in; интерфейсные тесты используют синтетические данные и точные semantic selectors.

## Пройдено

- Полный backend/source pytest под CPython 3.14.4: **2201 passed, 1 skipped**.
- Atlas: **19 passed**, включая детерминированную регрессию удерживаемого AI-turn и
  однократного списания при конкуренции. XLSX: **24 passed**, включая unsafe mutants.
- Сборщик контента проверил **590 исполняемых эталонов** в реальном CPython 3.14.4;
  выпущены **66 тем / 642 задания** и согласованный Android content bundle.
- React: typecheck passed; **90 tests passed / 28 files**; production build passed.
  Vite сообщает о крупных chunks. Утилита версии использовала fallback до Git init.
- Редакторская карта сгенерирована из текущих источников, `curriculum_quality.py --check` passed.
- Точные байты выбранного public/private TEACHING-поколения проверены capture_generation;
  это учебные метаданные, не данные учеников. Git attributes сохраняют frozen/vendor bytes.

Проверки запускались только на копии с временными DB/секретами и защитой от реальных model CLI,
внешних sandbox controls и live-портов. Node-проверки — FakeDOM/VM, браузер не запускался.

## Не проверялось

Живой сервер, реальные модели/аккаунты, рабочие данные, Docker/WSL runner, Android SDK/APK,
реальные устройства, браузерная/визуальная приёмка и равенство всех мигрируемых React-экранов.
Один skip не засчитывается как пройденный тест. Публичная копия не является развёртыванием
или подтверждением безопасности существующего интернет-сервиса.

Лицензии и manifest сторонних Pyodide/font/Gradle-компонентов сохранены. Выбор общей лицензии
проекта не подменяется лицензиями компонентов. Старый репозиторий с QA-историей остаётся private.
