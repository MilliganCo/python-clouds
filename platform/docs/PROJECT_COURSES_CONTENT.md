# Содержание проектных курсов

Сверка 23 октября 2026: 5 проектных курсов (25 этапов) и 16 локальных
мини-квестов (20 этапов). Порядок ниже совпадает с track_order витрины.
Источник условий доступа — project_courses.py и сгенерированный practice_quests.json;
источник локальных квестов и названий Python-тем — python_tasks_collection.md.
Номера обозначают стабильные ID, а не позиции карточек.

## Как читать условия

Для открытия этапа нужны темы открытия курса, обязательные темы самого этапа
и завершённые предыдущие этапы этого же курса. Полезные темы — подсказка,
а тема напоминания — повод предложить вернуться; они не добавляют блокировку.
Соседние проекты не нужно завершать по порядку. Пройденная тема включает
все её обычные этапы, в том числе оба обязательных финала; дополнительные боссы
не заменяют этот прогресс. Таблицы отражают код доступа, а не доказывают
педагогическую достаточность каждой предпосылки.

Сверка против действующего каталога: `cd platform; python -m pytest tests/test_project_dependency_docs.py -q`.

## Принципы контента

- Этапы не заменяют обычные темы.
- Каждый следующий этап меняет уже существующий код.
- Зависимости задаются через id тем, а не через позицию карточки в интерфейсе.
- Проверки не требуют единственного авторского решения, если поведение верное.
- Стартовый код должен быть понятной опорой, а не готовым ответом.
